# AI-Folio 🚀

A modern, professional portfolio website showcasing my projects, skills, and achievements as an AI Architect and Web Developer.

## ✨ Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations and transitions
- **Dynamic Content**: Typing animation, parallax effects, and interactive elements
- **Project Showcase**: Featured projects from my GitHub repositories
- **Skills Display**: Comprehensive overview of technical skills and expertise
- **Achievements**: Highlighting hackathon wins, leadership roles, and impact metrics
- **Contact Section**: Easy ways to connect via social media platforms

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for better accessibility
- **CSS3**: Modern styling with gradients, animations, and responsive design
- **JavaScript**: Interactive features and dynamic content
- **Font Awesome**: Icon library for visual elements

## 🚀 Quick Start

### Local Development

1. Clone the repository:
```bash
git clone https://github.com/sobiswriter/AI-Folio.git
cd AI-Folio
```

2. Open `index.html` in your web browser:
```bash
# On macOS
open index.html

# On Linux
xdg-open index.html

# On Windows
start index.html
```

That's it! No build process or dependencies required.

### Deployment Options

#### GitHub Pages

1. Go to your repository settings
2. Navigate to "Pages" section
3. Select the branch (e.g., `main`) and root folder
4. Click "Save"
5. Your site will be available at `https://sobiswriter.github.io/AI-Folio/`

#### Netlify

1. Create an account on [Netlify](https://netlify.com)
2. Click "New site from Git"
3. Connect your GitHub repository
4. Set build command: (leave empty)
5. Set publish directory: `/`
6. Click "Deploy site"

#### Vercel

1. Create an account on [Vercel](https://vercel.com)
2. Click "New Project"
3. Import your GitHub repository
4. Click "Deploy"

## 🎨 Customization

### Update Personal Information

Edit `index.html` to update:
- Your name and title
- About section content
- Projects (add/remove project cards)
- Skills and technologies
- Social media links

### Modify Colors

Edit `styles.css` to change the color scheme:
```css
:root {
    --primary-color: #00F5D4;     /* Main accent color */
    --secondary-color: #F72585;    /* Secondary accent */
    --accent-color: #7209B7;       /* Additional accent */
    --bg-dark: #0a0e27;           /* Background dark */
    --bg-darker: #050816;         /* Background darker */
}
```

### Add New Projects

In `index.html`, duplicate a project card and update:
- Project title
- Description
- GitHub link
- Tech stack tags
- Star/fork counts
